Directive hx-debounce
Default: 300ms Auto-Cancelling

Debounces user inputs, keystrokes, and clicks. Supports dot-path arguments like $event.target.value, custom delay overrides in milliseconds, and automatically cancels pending timers when the component state changes.

Immediate Raw Keystrokes: 0 Debounced API Calls: 0
Last Debounced Value: 
<!-- Bare method (default 300ms on 'input') -->
<input hx-debounce="handleSearch">

<!-- Custom delay (400ms) with event argument -->
<input hx-debounce="[handleSearch($event.target.value), 400]">

<!-- Debounce button click (1000ms) -->
<button hx-debounce:click="[saveDraft(), 1000]">Save</button>
Directive hx-collapse
.duration.<ms> .min.<px>

Smoothly animates height between 0px (or a custom minHeight) and natural scrollHeight using hardware-accelerated CSS transitions. Automatically clears fixed inline styles once fully expanded.

Interactive Accordion Panel
Hardware-Accelerated Smooth Collapse

Helix automatically calculates exact scroll height, applies a synchronized CSS transition, and clears overflow upon completion so dropdowns and tooltips inside aren't clipped.

Supports dynamic content changes and rapid click reversals without jumping!
Preview Panel (min. 45px)
Preview Summary: This panel never completely disappears because .min.45px keeps the first line visible even when closed. When expanded, it seamlessly grows to full height!

<div hx-collapse="isOpen">
  <p>Smoothly animated content...</p>
</div>

<!-- Custom 400ms duration modifier -->
<div hx-collapse.duration.400ms="isOpen">
  ...
</div>

<!-- Minimum height modifier for peek preview -->
<div hx-collapse.duration.300ms.min.45px="isOpen">
  ...
</div>
Directive hx-trap
.noscroll .inert

Traps keyboard focus (Tab / Shift+Tab) within a modal or dialog. Supports .noscroll (locks body scroll with nested reference counting) and .inert (deep-tree background isolation for accessibility).

Open the modal below. Notice that you cannot Tab outside of it, background page scroll is locked, and all outside elements are marked inert="true". Closing it restores focus to this button! 

<!-- Focus trap with scroll lock & deep inert -->
<div hx-trap.noscroll.inert="isModalOpen" class="modal-dialog">
  <h5>Accessible Modal Dialog</h5>
  <input type="text" placeholder="First Name" />
  <button @click="closeModal">Close</button>
</div>

<!-- Features:
  ✓ Loops Tab and Shift+Tab navigation
  ✓ Reference-counted body scroll locking
  ✓ Deep ancestor-guarded inert isolation
  ✓ Restores focus safely on close -->
Focus Trapped Modal

Press Tab or Shift + Tab repeatedly. Focus will cycle strictly through these inputs and buttons without escaping into the page.

Directive hx-clipboard
.class.<name> .duration.<ms>

Copies bound context values or element text content to the user's system clipboard. Provides instant visual feedback classes and dispatches a rich @copied CustomEvent.

npm i @helix-js/directives
// @copied Event Console:
<!-- Copy context variable with custom feedback class & duration -->
<button hx-clipboard.class.is-copied.duration.1500="shareUrl">
  Copy Link
</button>

<!-- Listen to @copied event with payload -->
<button hx-clipboard="token" @copied="onCopied($event)">
  Copy Token
</button>

<!-- Event detail payload structure:
  event.detail = {
    text: "https://helixjs.org",
    success: true
  } -->
Directive hx-intersect
.once .half / .full .threshold.<pct> :leave

Executes reactive callbacks when an element enters or leaves the browser viewport. Supports percentage thresholds (.threshold.50, .half), root margins, and unobserve cleanup.

<!-- Trigger when 50% visible -->
<div hx-intersect.threshold.50="loadMore">...</div>

<!-- Fire once and disconnect observer -->
<div hx-intersect.once="fetchAnalytics">...</div>

<!-- Root margin offset (with negative margins) -->
<div hx-intersect.margin.-50px="onNearScreen">...</div>

<!-- Detect when leaving viewport -->
<div hx-intersect:leave="pauseVideo">...</div>
