Detailed Predicate Reference (where, when, like, and more)
.where()
Evaluates column comparisons (=, !=, <, <=, >, >=), object hashes, or custom callbacks. 
// Standard 3-arg or 2-arg equality
m.where('price', '<=', 300);
m.where('category', 'Electronics');

// Hash / Object dictionary
m.where({ active: true, inStock: true });

// Custom Callback predicate
m.where(item => item.price * 1.1 > 500);
.when() / .unless()
Conditionally append query clauses only when the first argument is truthy (or falsy in unless) without breaking method chaining. 
// Applies filter ONLY when selectedRole is present
m.when(selectedRole, (query, role) => {
  return query.where('role', '=', role);
}, (query) => {
  // Optional fallback when falsy
  return query.where('role', '!=', 'banned');
});
'like' Operator
Case-insensitive substring match inside string fields, equivalent to SQL LIKE %term%. 
// Match substring inside product name
m.where('name', 'like', 'pro');

// Compact 2-argument SQL syntax
m.where('name like', 'air');

// Negative substring check ('not like')
m.where('sku', 'not like', 'TEST');
.orWhere()
Appends an OR branch to the AST query tree, allowing matches that satisfy either condition. 
// Matches Apple OR Bose products
m.where('brand', '=', 'Apple')
 .orWhere('brand', '=', 'Bose');
.whereIn() / .whereNotIn()
Check if a column value exists (or does not exist) within an array of candidates. 
// Keep only Electronics or Audio
m.whereIn('category', ['Electronics', 'Audio']);

// Exclude deleted or archived records
m.whereNotIn('status', ['archived', 'trash']);
.whereBetween()
Inclusive numeric or date range filter checking whether `min <= field <= max`. 
// Price between $100 and $500 (inclusive)
m.whereBetween('price', [100, 500]);

// Rating outside low spectrum
m.whereNotBetween('rating', [0, 2.5]);
.whereNull() / .whereNotNull()
Filter items where a field is `null` or `undefined` (or defined and non-null). 
// Find items missing a discount code
m.whereNull('discountCode');

// Find verified accounts only
m.whereNotNull('verifiedAt');
.search()
Multi-field fuzzy case-insensitive substring search across any array of fields. 
// Searches name, category, and brand simultaneously
m.search(['name', 'category', 'brand'], 'apple');

Complete API Matrix & Method Reference
Alphabetical and functional catalog of all 60+ built-in collection and query methods.
Method Description Example Usage
.where(field, op, val) Filter rows matching operator comparison .where('age', '>=', 18)
.where(object) Key-value equality filter .where({ active: true, role: 'admin' })
.whereIn(field, array) Check if field matches any value in array .whereIn('status', ['paid', 'shipped'])
.whereBetween(field, [min, max]) Inclusive numeric or date range filter .whereBetween('score', [50, 100])
.search(fields, query) Case-insensitive multi-field search .search(['name', 'email'], 'john')
.orderBy(field, dir) Sort items by column ascending/descending .orderBy('price', 'desc')
.paginate(perPage, page) Returns structured pagination metadata .paginate(10, 1)
.pluck(field) Extract single column as flat array .pluck('email')
.sum(field) / .avg(field) Calculate mathematical sum or average .sum('amount')
.groupBy(field) Group items into object by key .groupBy('department')
.index(field) Construct O(1) Map index for rapid lookups .index('sku').find('SKU-1')
.innerJoin() / .leftJoin() Relational join against another collection .leftJoin(orders, 'userId', 'id')
.computed() / .live() Signal-native reactive view derivation .where('active', true).computed()
.update(attrs) / .delete() Mass in-place mutation of matching rows .where('id', 5).update({ paid: true })
.findAll(limit?, offset?) CI4 & Laravel style eager query execution: returns all items, with optional limit & offset .where('active', true).findAll(10, 0)
